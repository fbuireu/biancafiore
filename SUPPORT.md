# Support

This repository builds one site, [biancafiore.me](https://biancafiore.me), and it is maintained by one person.

## If you are reading the site

The quickest route to Bianca is the site itself: the [contact form](https://biancafiore.me/contact) reaches
her inbox directly, and it is the right place for anything about the writing, a commission, or a correction to
an article. You do not need a GitHub account, and an issue opened here is slower rather than faster.

## If something on the site is broken

A layout that breaks, a page that errors, an image that never loads: open a
[bug report](https://github.com/fbuireu/biancafiore/issues/new?template=bug_report.yml) with the page URL, the
browser and whether it reproduces in a second one. Rendering here leans on modern CSS deliberately, so the
browser and its version are usually the whole answer.

**The articles are not in this repository.** They live in Contentful, and the site reads them at build time,
so a typo in an article is fixed there rather than here: use the
[content issue](https://github.com/fbuireu/biancafiore/issues/new?template=content_issue.yml) template, or the
contact form.

## Vulnerabilities

Privately, through the [security policy](https://github.com/fbuireu/biancafiore/security/policy), never as a
public issue. [SECURITY.md](./SECURITY.md) says what is in scope.
